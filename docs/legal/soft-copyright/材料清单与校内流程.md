## 二、总流程地图

```
① 备齐鉴别材料 + 信息表
        ↓
② 有度 → 工作 → 网上办事大厅 → 科研服务类 → 知识产权申请
   （上传材料，按流程审批）
        ↓
③ 审批通过后：相关纸质到校办盖章
   （南曦园107；非代理路径无「代理合同」环节）
        ↓
④ 登录中国版权保护中心 www.ccopyright.com.cn
   3.1 软件登记
   3.2 计算机软件著作权登记申请
   3.3 我是代理人
   3.4 著作权人＝北京师范大学珠海校区
   3.5 填写提交材料清单
   3.6 提交申请 → 电话 0756-3683537
       凭流水号末六位获取授权码
   3.7 打印《计算机软件著作权登记申请表》
        ↓
⑤ 申请表 + 信息表 + 统一社会信用代码证书复印件 等盖校章后，按系统/科研办要求完成后续上传或邮寄
```

科研办联系（校方页）：电话 **0756-3683537**；木铎楼 A301；邮箱 zhkyb@bnu.edu.cn；邮编 519087。

## 三、不委托代理机构 — 校内应交纸质/扫描

据科研办说明，非代理路径至少包括：

1. 《北京师范大学珠海校区知识产权申请信息表》（官网可下载）  
2. 《计算机软件著作权登记申请表》（CCPC 系统填写后打印）  
3. 申请学校**统一社会信用代码证书复印件（加盖校章）**

另：有度系统审批单；鉴别材料按 CCPC 要求电子上传（源程序 + 文档）。

## 四、必须本人（或本人到场）办理的事项

| # | 事项 | 说明 |
|---|------|------|
| 1 | **有度网上办事大厅**发起「知识产权申请」并跟完审批 | 别人代登有度一般不合规；材料可先备好再上传 |
| 2 | **打电话 0756-3683537** 用 CCPC 流水号末六位要**授权码** | 校方明确由申请人联系 |
| 3 | **到校办（南曦园 107）盖章** | 信息表、申请表、信用代码证书复印件等；非代理无代理合同打印环节 |
| 4 | **下载并填写校内《知识产权申请信息表》** | 本目录未伪造该表；请从科研办页面下载空白表 |
| 5 | **确认职务权属请示结果** | `职务软件权属请示-如是我闻` 是否已获科研院/校区同意以学校为权利人 |
| 6 | **核对信用代码证书** | 公开信息常见码 `12100000717801841W`（多标注「珠海分校」）；**以盖章证书为准** |
| 7 | CCPC 账号实名**、上传身份证等 | 代理人白军伟 |
| 8 | 最终是否网上「提交」 | 本助手**未提交**；由你在授权码与盖章齐备后自行点提交 |

## 六、交件前请你再核的风险点（Blockers）

1. **权属请示是否批下来** — 未批则不宜用学校名义对外提交。  
2. **说明书封面著作权人仍为「沂南灵创技术服务中心」** — 与本次「珠海校区」登记不一致；建议改封面再交，或按科研办口头/书面意见处理。  
3. **统一社会信用代码** — 草稿中的码须与**盖章证书**一致后再写入正式表。  
4. **有度信息表空白未填** — 须从校方下载填写。  
5. **授权码未取** — 依赖 3.6 提交后的流水号 + 电话。  
6. **本目录助手未做网上提交、未改 git remote、未推送。**
