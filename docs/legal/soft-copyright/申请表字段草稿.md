## 6. 主要功能（填表用短文）

本软件提供桌面端中文录音/音频的本地转写与校对能力，主要包括：

1. **项目管理**：新建项目、导入本地音频、场次元信息（讲述人、时间、地点等）。  
2. **本机转写**：通过本机 ASR 侧车完成中文语音识别；支持长音频分窗与进度反馈。  
3. **在线转写（可选）**：配置第三方在线 STT 服务密钥后调用云端识别。  
4. **语段编辑与校对**：波形对照、语段拆分/合并、说话人标注、词表与纠错记忆。  
5. **导出**：TXT / SRT / DOCX 等；可导出诊断包便于排障。  
6. **更新**：通过官方 CDN（`updates.rushi.app`）检查与安装更新。

## 7. 技术特点（填表用短文 · 划清第三方边界）

1. **桌面架构自研**：基于 Tauri 2 + React + SQLite 实现项目/语段持久化、编辑器与导出流水线（非 Electron）。  
2. **本机 ASR 编排自研**：Python FastAPI 侧车负责模型准备、分窗转写、与桌面端的 HTTP 契约；**识别引擎本体采用第三方 FunASR / ModelScope 等开源组件（Apache-2.0 等），不主张为其算法本身登记权利**。  
3. **原生播放与波形**：Rust 原生音频播放与长波形视口/跟随等为自研集成；波形可视化可使用 WaveSurfer 等库，算法库本身为第三方。  
4. **可选模块**：说话人相关能力可调用第三方说话人模型；FFmpeg 用于音视频规范化（许可见安装包第三方声明）。  
5. **专有产品许可**：发行许可为专有软件；第三方清单见 `third-party-notices` / 关于页。
