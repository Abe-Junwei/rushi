# 导出 LLM 保真整理与讲稿优化：Intent

> **Research**：[`export-llm-fidelity-and-lecture-optimize-research.md`](./export-llm-fidelity-and-lecture-optimize-research.md)  
> **状态**：已实施

## 目标

1. 将现有导出行为正式命名为 **LLM 保真整理**：本地稳定规则改错字，LLM 只改标点/空白和自然段。
2. 为“讲稿”新增 **讲稿优化**：LLM 可提议去赘词/重复、修语病、理顺口语，并直接导出 Word 修订稿。
3. 优化不写回 SQLite 语段，只影响本次 DOCX；用户可在 Word 中逐条接受或拒绝每一处修订。

## 用户心智

- **逐字稿**：不用 LLM，保留逐语段时码与当前正文。
- **LLM 保真整理**：当前“干净稿”能力，正文不增删改，只整理标点和自然段。
- **讲稿优化**：直接导出带完整修订轨的讲稿，在 Word 中逐条审核；接受保留优化，拒绝恢复对应原文。

普通“讲稿/按当前语段”与逐字稿在内容上重复，v1 从导出 UI 移除，不再作为独立产品能力。

## 讲稿优化允许与禁止

**允许**：

- 去除语段内口头赘词、明显重复和无意义结巴。
- 修正明显语病，将口语语序调整为可读书面语。
- 统一标点、空白与自然段。

**禁止**：

- 新增原文没有的事实、论点、数字或人名。
- 摘要、压缩为提纲、改变立场。
- 调换语段顺序、合并 ID、删除整个非空语段。
- 静默覆盖编辑器或数据库正文。

## 不做什么

- v1 不支持将优化建议写回项目。
- v1 不在 Rushi 内提供逐语段预览、勾选或确认界面，Word 是唯一审核面。
- v1 不支持整语段删除、跨语段重排或时间轴变更。
- 不修改保真整理的信任边界和现有完整性门禁。
